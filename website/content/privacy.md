## 本政策说明什么

本政策说明 ZPad 应用与官网 zpad.xphub.dev 如何处理与访问相关的信息。它不覆盖 GitHub、MyGo 官网等第三方站点，那些站点适用各自的隐私政策。

## 应用

ZPad 在本地处理你的文件，不上传、不分析、不同步，也不包含遥测、崩溃上报或使用统计。唯一的网络请求是启动后向 GitHub 检查更新，请求里只有版本号与平台信息。文件名、路径和正文都不会离开你的设备。

## 官网访问日志

官网托管在 Cloudflare Pages。为了让站点可访问并防御攻击，Cloudflare 会处理访问日志，包括 IP 地址、浏览器标识（User-Agent）、访问时间和请求路径，按其隐私政策保存与使用。

## 访问统计

官网使用自建的统计脚本，用来了解下载页与各版本的访问情况。记录的内容是：访问的页面、来源、由 IP 推断的大致国家或地区、设备与浏览器类型、访问时间。IP 不写入统计报表，也不与其它数据合并。

- 不使用 cookie，不在你的浏览器里保存标识。
- 不跨站追踪，不做广告画像，不与第三方共享或出售。
- 统计明细仅在汇总分析所需期间保留，不做长期归档。
- 想完全关闭统计：使用无痕模式、拦截脚本，或阻止统计域名即可。

## 本地存储

官网只在浏览器的 localStorage 里保存一项主题偏好（亮 / 暗），用来保持显示一致。它不用于识别身份，清除浏览器数据即可删除。应用不写入任何浏览器存储。

## 第三方链接

官网的下载按钮跳转到 GitHub Releases，源码与反馈入口指向 GitHub，页脚另有 MyGo 官网链接。这些站点由第三方运营，适用它们自己的隐私政策。

## 数据共享与安全

我们不收集、不出售、不共享个人信息。官网与统计服务可能在你所在国家或地区之外处理访问日志；全站通过 HTTPS 传输，收集范围保持在运行与分析所需的最小限度。

## 未成年人

ZPad 不面向未成年人设计，也不主动收集任何人的年龄信息。

## 你的权利与联系方式

官网不保存可识别到个人的数据，通常无法按人查询或删除某次访问；如果你对某项处理有疑问、想反对或投诉，可以在 [GitHub](https://github.com/helloxz/zpad/issues) 提交 issue，我们会说明数据的处理方式。

## 政策更新

本政策随功能变化调整，最新版本始终在本页，更新日期见页面顶部。涉及统计方式或第三方服务的重大变更，会在页面上方标注。
