# 00 · 最终需求

## 1. 产品定位

ZPad 是一个**轻量级原生文本 / 代码编辑器**，面向日常查看、快速修改和轻量开发：

- 打开一个文件夹或几个文件，快速浏览与编辑。
- 重点支持 HTML、CSS、JavaScript、JSON、Markdown、纯文本。
- 不追求 IDE 级能力（不做 LSP、调试器、Git 面板、插件系统）。
- 界面现代、启动快、内存占用低。

## 2. 目标平台

| 优先级 | 平台 | 说明 |
| --- | --- | --- |
| P0 | macOS | 先在本机跑通并发布 |
| P1 | Windows x64 | macOS 稳定后再适配 |
| P2 | Linux x64 | 最后考虑；原生 UI 依赖 GTK3 |

一期只对 macOS 做完整验收；其余平台的代码保持可编译，但不作为一期验收条件。

## 3. 一期范围（P0）

### 3.1 布局

```
┌──────────────────────────────────────────────────────────┐
│ 工具栏：打开 / 保存 / 撤销 / 查找 / 大小写 / 分屏 / 设置… │
├──────────────┬───────────────────────────────────────────┤
│ 侧栏（可关） │ 标签栏                                     │
│ 文件树       ├───────────────────────────────────────────┤
│              │ 编辑区 A          │ 编辑区 B（可选）       │
│              │                   │                        │
├──────────────┴───────────────────┴────────────────────────┤
│ 状态栏：路径 · 语言 · 编码 · 换行 · 行列 · 选区 · 大小     │
└──────────────────────────────────────────────────────────┘
```

- 单窗口。
- 左右最多两栏，中间一条可拖拽的垂直分隔线。
- 每栏有独立的标签页和当前文件。
- 侧栏默认关闭，可通过工具栏或设置开启；分为「打开的文件」和「工作区」两个 Tab，默认显示打开的文件；首次打开文件夹时自动展开并切到工作区。
- 工作区文件树支持右键：在副窗口打开、重命名、删除（文件和文件夹）。
- 「打开的文件」列表对已保存文件提供在副窗口打开、重命名、删除。
- 标签右键菜单：关闭当前 / 左侧 / 右侧标签，移动到主窗口 / 副窗口，复制到主窗口 / 副窗口；未分屏且只有一个标签时「移动到副窗口」不可用。
- 标签拖拽排序：栏内拖动改变标签顺序，拖动时在标签栏显示插入位置；拖到另一栏的标签栏按落点插入，拖到编辑区追加到末尾；拖拽不切换活动标签。
- 侧栏宽度可拖拽，并持久化。

### 3.2 文件与文档

- 新建文件（未命名）。
- 打开单个文件。
- 打开文件夹作为工作区。
- 保存、另存为、关闭标签。
- 已保存文件可在状态栏路径旁或标签右键菜单调用系统文件管理器定位；未命名文件不显示该按钮。
- HTML 文件可在系统浏览器中打开：状态栏语言标签旁的浏览器按钮、标签右键菜单或 `⌘⇧B`；有未保存修改时先保存。
- 未保存标记：标签上的圆点 + 窗口标题 / macOS 关闭按钮状态。
- 关闭未保存标签时提示：保存 / 不保存 / 取消。
- 关闭窗口或退出应用时汇总提示：保存全部 / 不保存 / 取消。
- 原子写入：先写临时文件，再替换目标文件，避免半写坏文件。
- 保留文件权限与符号链接的基本行为。

### 3.3 编辑器

基于 MyGo 的 `ui/editor`：

- 语法高亮：HTML、CSS、JavaScript、JSON、Markdown、纯文本。
- 多光标与多选区。
- 撤销 / 重做。
- 代码折叠。
- 自动闭合括号与引号。
- 软换行开关。
- 行号开关（绝对 / 相对 / 关闭）。
- 缩进参考线。
- 当前行高亮。
- 跳转到行（`Ctrl+G`）。
- 输入法（中文、日文等）正常组合输入。
- 大文件按行虚拟化，不一次性绘制全部内容。
- Markdown 原生预览：标签内切换源码 / 预览；状态栏语言旁、`⌘⇧V`、`Esc`（焦点在窗口任意位置）、标签右键菜单或编辑器正文右键菜单；分屏可源码 + 预览。新建的未命名文件在状态栏选择 Markdown 后同样可以预览。支持 GFM、代码高亮、本地图片、远程图片（http / https 与 `data:`）和链接；预览图片长边按 756 DIP 阅读栏 2× 显示上限缩到 1512 px，单图上限 10 MB、2400 万像素、15 秒超时，远程图片原始字节缓存在系统临时目录，退出预览释放内存位图，超出或加载失败显示 alt 占位块。原始 HTML、MDX 不渲染，超过约 1 MB / 1 万行不启用。

### 3.4 查找与替换

直接使用编辑器内建 FindBar：

- `Cmd+F` 查找，`Cmd+Alt+F` 替换。
- 大小写敏感。
- 全词匹配。
- 正则表达式。
- 仅在选区内查找。
- 上一个 / 下一个。
- 替换一个 / 全部替换。
- FindBar 的视觉样式重绘为 ZPad 风格。
- `Cmd+Shift+F` 在居中浮层中搜索所有已打开标签（两个分栏、含未保存内容和未命名文件）：输入或切换选项后按回车或点击右侧搜索按钮扫描，结果按文件分组，`↑`/`↓` 选择，回车打开选中项。关闭面板保留关键词和结果，输入框末尾的 X 清空后才丢弃；`Esc` 只关闭面板。不读取磁盘上的未打开文件，工作区文件搜索仍属二期。

### 3.5 大小写转换

对当前所有选区生效；没有选区时，自动选取光标所在单词。

- 转为大写。
- 转为小写。
- 首字母大写（每个单词）。
- 反转大小写。
- 多选区一次性转换，作为一次撤销步骤。
- 入口：编辑菜单、右键菜单；可选工具栏菜单。

### 3.6 编码

支持：

- UTF-8
- UTF-8 with BOM
- UTF-16 LE
- UTF-16 BE
- GB18030（兼容 GBK）

打开时的检测顺序：

1. 检查 BOM：
   - `EF BB BF` → UTF-8 BOM
   - `FF FE` → UTF-16 LE
   - `FE FF` → UTF-16 BE
2. 无 BOM 时校验是否为合法 UTF-8；合法则按 UTF-8 打开。
3. 否则尝试按 GB18030 解码。
4. 仍失败或出现异常控制字符比例过高时，弹窗让用户手动选择编码。

编码切换有两种明确语义，不要混用：

- **重新以…编码打开**：按目标编码重新读取磁盘字节，替换当前文本；要求当前文件没有未保存修改，否则先提示。
- **以…编码保存**：保持当前文本，按目标编码写盘；保存成功后状态栏编码更新。

保存前做编码往返校验：目标编码无法表示的字符要提示，建议改用 UTF-8 保存，不能静默替换成 `?`。

BOM 作为独立选项处理：选择 UTF-8 时保存不带 BOM，选择 UTF-8 BOM 时保存带 BOM。

### 3.7 换行符

- 状态栏显示当前主要换行符：LF / CRLF / CR。
- 点击可转换为 LF、CRLF 或 CR。
- 保存时按缓冲区当前的实际行尾写入，保留混合行尾的原始行为。
- 新建文件使用设置中的默认换行符（默认 LF）。

### 3.8 主题

默认三档保持不变：

- ZPad 亮色
- ZPad 暗色
- 跟随系统

另有 18 套命名主题（One Dark、Dracula、Nord、Tokyo Night、Catppuccin Mocha、Monokai、Gruvbox Dark、Ink Night、GitHub Light、One Light、Solarized Light、Catppuccin Latte、Gruvbox Light、Rosé Pine Dawn、Ayu Light、Everforest Light、Celadon、Ink Wash），细节见 [08-themes.md](./08-themes.md)。

实现要点：

- 使用 `mygo.Theme.SetSource(mygo.ThemeLight / ThemeDark / ThemeSystem)` 强制应用外观，使原生菜单、对话框、标题栏也跟随；命名主题按其亮 / 暗基准设置。
- UI 主题：工具栏、侧栏、标签、状态栏、设置面板各自一套颜色；侧栏、标签栏与活动标签的背景由主题定义，不再按亮 / 暗写死。
- 编辑器主题：基于 `editor.DefaultTheme(t)`，覆盖关键字、字符串、注释、数字、函数、类型等 token 颜色。
- 跟随系统时，以 `c.Theme()` 为基底，按系统外观选择 ZPad 亮色 / ZPad 暗色调色板；命名主题固定明暗。
- 主题选择在设置 → 外观的下拉选择中完成，按默认主题 / 深色 / 浅色分组，命名主题的浅色 / 深色标注在行右侧对齐，长列表在弹层内滚动；原生菜单保留三档默认项并提供「更多主题…」，工具栏不设主题按钮。
- 切换后立即生效并持久化；未知主题 id 回退「跟随系统」。

### 3.9 字体

- 编辑器默认使用系统等宽字体，13 DIP，行高 1.5。
- 设置中可选择字体家族，只列出等宽字体：
  - 内置字体：JetBrains Mono（OFL 许可，随应用打包）。
  - 系统字体：通过 `ui.FontFamilies()` 读取，过滤 `Monospaced`。
- 字号可调：10–28 DIP。
- 行高可调：1.2–2.0。
- UI 字体保持系统界面字体，不跟随编辑器字体。
- 内置字体通过 `//go:embed` + `ui.RegisterFont` 注册。

### 3.10 国际化

- 支持简体中文与英文。
- 默认跟随系统语言。
- 设置中可选：跟随系统 / 简体中文 / English。
- 使用 MyGo 的 i18n catalogs（`locales/en.json`、`locales/zh.json`），运行期通过 `App.SetLocale` 切换，无需重启。
- 应用自身文案、菜单项、设置项、错误提示全部覆盖。
- MyGo 自带控件文案（查找栏、对话框等）随应用语言一起切换。
- 代码内使用英文 key，英文为源语言。

### 3.11 状态栏

左侧：

- 当前文件相对路径（无工作区时显示绝对路径）；已保存文件在路径旁显示「在文件管理器中显示」按钮。
- 语言名称；HTML 文件在语言旁显示「在浏览器中打开」按钮。
- 编码。
- 换行符。
- 自动换行开关：图标按钮，排在最右侧，开启时用强调色；与设置面板里的开关、视图菜单的勾选项和 `⌥Z` 是同一个全局设置，大文件与只读文件下禁用并说明原因。

右侧：

- 行列位置（1 基，列按字符而不是字节）。
- 选区字符数（有选区时）。
- 文件大小。
- 未保存状态。

编码与换行符是可点击菜单；路径与语言本身是只读信息，旁边的两个图标分别提供文件管理器定位和 HTML 浏览器打开。自动换行按钮只是设置面板里同一个全局开关的快捷入口，切换后写盘并立即作用于所有标签页。

### 3.12 设置

模态面板，卡片分组；每行左侧标题与说明，右侧控件，窄窗口下控件换到标题下方。设置内的下拉均为自绘，选项悬停显示小手。

**外观**
- 主题：ZPad 亮色 / ZPad 暗色 / 跟随系统，以及 18 套命名主题的下拉选择（浅色 / 深色标注右对齐）
- 界面语言：跟随系统 / 简体中文 / English

**编辑器**
- 字体家族（等宽）
- 字号
- 行高
- 软换行
- 行号：绝对 / 相对 / 关闭
- Tab 大小
- 缩进：空格 / Tab
- 缩进参考线
- 自动闭合括号

**文件**
- 默认编码
- 默认换行符
- 大文件阈值（默认 20 MB）

**工作区**
- 侧栏默认关闭（打开文件夹时自动展开）
- 启动时恢复上次会话（默认开启）
- 保留未保存内容（默认开启）
- 关闭时确认未保存文件

设置修改后立即生效，写入 `settings.json`；有“恢复默认”入口。

### 3.13 会话恢复

保存到 `session.json`：

- 上次打开的工作区目录。
- 左右分栏是否开启、分隔线位置。
- 每栏打开的标签（路径、顺序、当前标签）。
- 当前焦点栏。
- 每个标签的滚动位置。
- 侧栏是否显示、宽度。
- 主题、语言、字体等设置单独存在 `settings.json`。
- 窗口位置和大小通过 MyGo `StateKey: "main"` 记忆。

一期只恢复已保存文件；未保存内容的热退出放二期。

### 3.14 文件关联与拖拽

- 在 `mygo.json` 声明常见文本扩展名。
- 通过 `App.OnOpenFile` 接收 Finder / 命令行打开的文件。
- 拖入文件：在活动栏打开。
- 拖入文件夹：作为工作区打开。
- 拖拽悬停时显示高亮边框。
- 单实例：Windows / Linux 上第二次打开交给已运行实例，由其前置窗口并打开文件；`.ext\OpenWithProgids` 只登记到「打开方式」，默认应用由用户选择。

建议关联扩展名：

```
文档与数据：txt log csv md markdown mdx mkd html htm xhtml
            css scss less sass pcss xml json jsonc json5 webmanifest
            yaml yml toml ini conf properties editorconfig diff patch rej
源码：      js mjs cjs jsx ts tsx mts cts vue svelte
            go py pyi pyw rs c h cpp cc cxx hpp hh hxx
            java kt kts scala swift dart cs rb rake lua php zig
            sh bash zsh fish ksh sql r proto graphql gql graphqls
            tf tfvars hcl nix erb rhtml tt j2 jinja jinja2
```

无扩展名文件（Dockerfile、Makefile、README 等）无法关联，但打开时按文件名识别语法；`.command`、`.plist`、`.svg`、`.xib`、`.storyboard`、`.csproj` 等可执行或系统资产类型不纳入关联，避免抢系统默认处理程序。

## 8. 性能与限制

- 单个文件超过 **20 MB**：提示后以只读方式打开。
- 超过 **50 万行**：提示后以只读方式打开。
- 二进制文件（前 8 KB 含 NUL 字节）：拒绝打开并提示。
- 读取、编码转换、保存均在 goroutine 中执行，完成后通过 `Window.Update` 回到 UI 线程。
- 目录树只读取当前展开层级；大目录使用虚拟化 Outline。
- 查找替换使用编辑器内建实现，不额外复制全文。

## 9. 验收总则

- macOS 上 `go tool mygo dev` 可启动，`go tool mygo build` 可产出 `.app`。
- 全流程不出现 WebView。
- `go test ./...` 通过。
- 主要操作可仅用键盘完成。
- 错误提示使用当前界面语言，且不丢失用户内容。
- 未保存内容不会因崩溃、误关闭或编码转换而静默丢失。

## 10. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 编码自动检测不准确 | BOM → UTF-8 → GB18030 回退；始终允许手动“重新以…编码打开” |
| GB18030 无法表示某些字符 | 保存前往返校验；提示改用 UTF-8 |
| 强制暗色与系统原生控件不一致 | 使用 `mygo.Theme.SetSource` 统一外观 |
| 关闭流程重复弹窗 | 统一由一个关闭协调器处理窗口关闭与退出 |
| 大文件卡顿 | 阈值 + 只读模式 + 后台读取 |
| MyGo API 变动 | `go.mod` 固定版本，升级前跑全量测试 |
| 字体打包体积 | 只内置一套 JetBrains Mono，其余用系统字体 |
| AGPL 分发义务 | 对外发布前确认源码提供方式 |
