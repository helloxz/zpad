# 04 · M3 视觉、设置、字体与中英双语

> 预估：2 天
> 前置：M2 已签收

## 1. 目标

让 ZPad **看起来像一个成品**：统一的亮 / 暗配色、精致的编辑器主题、
完整的设置面板、可选的等宽字体，以及无需重启的中英切换。

## 2. 范围

### 做

- 亮色 / 暗色完整调色板。
- 编辑器 token 配色、查找栏、跳行栏、滚动条、焦点环。
- 设置模态面板（外观 / 编辑器 / 文件 / 工作区）。
- 内置 JetBrains Mono + 系统等宽字体选择。
- 字号、行高可调。
- 中英双语 catalogs，运行期切换。
- 工具栏与状态栏最终样式。
- 空状态、toast、错误提示。
- 可访问性：标签、焦点顺序、快捷键提示。
- 测试。

### 不做

- 自定义主题导入 / 导出。
- 更多内置字体。
- Windows / Linux 的字体与主题差异适配。

## 4. 任务拆解

### 4.1 主题落地

- [ ] `internal/theme` 提供完整 `Light()` / `Dark()` / `System()`。
- [ ] 应用主题：

```go
mygo.Theme.SetSource(source) // ThemeLight / ThemeDark / ThemeSystem
c.SetTheme(theme.UITheme(c, app.settings.Theme))
```

- [ ] 跟随系统时按 `c.Theme()` 的背景亮度选择亮 / 暗调色板。
- [ ] 工具栏、侧栏、标签、状态栏、设置面板分别应用对应颜色。
- [ ] 编辑器：

```go
th := editor.DefaultTheme(c.Theme())
th.Tokens[editor.TokenKeyword] = editor.TokenStyle{Color: ..., Bold: true}
app.code.Theme = th
```

- [ ] 重绘查找栏：`RenderFindBar`，与工具栏同一套圆角、背景、阴影。
- [ ] 重绘跳行栏：`RenderGoToLine`。
- [ ] 滚动条：`ui.ScrollbarStyle`，细、圆角、悬停明显。
- [ ] 焦点环：`FocusRingWidth` / `FocusRingOffset` 与整体风格一致。
- [ ] 强制暗色时验证原生菜单、文件对话框、消息框均为暗色。

### 4.2 设置面板

- [ ] 使用 `ui.Modal`，分四组，可滚动。
- [ ] 外观：
  - 主题：`ui.Segmented`（亮色 / 暗色 / 跟随系统）
  - 语言：`ui.Select`（跟随系统 / 简体中文 / English）
- [ ] 编辑器：
  - 字体家族：`ui.Select`，只列 `ui.FontFamilies()` 中 `Monospaced` 的字体。
  - 字号：`ui.NumberInput` 或 `ui.Slider`，10–28。
  - 行高：1.2–2.0，步长 0.1。
  - 软换行：`ui.Switch`。
  - 行号：绝对 / 相对 / 关闭。
  - Tab 大小：2 / 4 / 8。
  - 缩进：空格 / Tab。
  - 缩进参考线：`ui.Switch`。
  - 自动闭合括号：`ui.Switch`。
- [ ] 文件：
  - 默认编码：UTF-8 / UTF-8 BOM / UTF-16 LE / UTF-16 BE / GB18030。
  - 默认换行符：LF / CRLF / CR。
  - 大文件阈值：10 / 20 / 50 MB。
- [ ] 工作区：
  - 侧栏默认开启。
  - 启动时恢复会话。
  - 关闭时确认未保存文件。
- [ ] 修改立即生效；防抖写盘。
- [ ] “恢复默认”按钮，二次确认。
- [ ] 设置面板支持 Esc 关闭、Tab 焦点顺序合理。

### 4.3 字体

- [ ] 引入 JetBrains Mono（OFL 许可）：
  - `fonts/JetBrainsMono-Regular.ttf`
  - `fonts/JetBrainsMono-Bold.ttf`
  - `fonts/JetBrainsMono-Italic.ttf`
  - `fonts/JetBrainsMono-BoldItalic.ttf`
  - `fonts/OFL.txt`
- [ ] 注册：

```go
//go:embed fonts/*.ttf
var fontFS embed.FS

func init() {
    for _, name := range []string{"Regular", "Bold", "Italic", "BoldItalic"} {
        data, err := fontFS.ReadFile("fonts/JetBrainsMono-" + name + ".ttf")
        if err != nil {
            log.Fatal(err)
        }
        if err := ui.RegisterFont(data, "JetBrains Mono"); err != nil {
            log.Fatal(err)
        }
    }
}
```

- [ ] 字体列表：内置字体优先，其后系统等宽字体；去重、按名称排序。
- [ ] 字体缺失或加载失败时回退到系统等宽字体，并 toast 提示。
- [ ] 编辑器 `ui.Font{Family, Size}` 与 `LineHeight` 应用设置。
- [ ] UI 字体保持系统界面字体。

### 4.4 中英双语

- [ ] `locales/en.json` 与 `locales/zh.json`，英文为源语言。
- [ ] 所有应用文案使用生成的 typed 函数，不散落硬编码字符串。
- [ ] 菜单项、设置项、状态栏、空状态、错误提示、toast 全部覆盖。
- [ ] 语言切换：


- [ ] 切换后调用 `win.Update`，菜单重建，当前视图立即刷新。

- [ ] 日期、数字格式如涉及，使用 `i18n` 格式化。

### 4.5 工具栏与状态栏

- [ ] 工具栏分组：

  - 中间：撤销、重做、查找、大小写菜单。
  - 右侧：分屏、主题菜单、编码菜单、设置。
- [ ] 图标使用 Lucide SVG（`ui.Icon`），全部带 `Label` 与 `Tooltip`。
- [ ] 窄窗口时由 `ui.Toolbar` 自动收进溢出菜单。

- [ ] 状态栏未保存标记使用小圆点。

### 4.6 空状态与提示

## 7. 风险与备注

- 内置字体会增加应用体积（约 1–2 MB），可接受。
- 字体注册必须在创建任何窗口前完成。
- `ui.FontFamilies()` 首次调用可能耗时数十毫秒，应在启动后异步加载并缓存。
- 强制暗色依赖 `mygo.Theme.SetSource`，需在 macOS 上实际验证菜单与对话框。
- 中英文案需要一次完整走查，避免遗漏硬编码。
